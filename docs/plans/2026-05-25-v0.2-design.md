# xhs-research v0.2.0 设计方案

> 日期：2026-05-25
> 目标：双引擎架构 + 对比功能 + 报告质量提升

## 1. 双引擎架构

Scraper 层支持两种数据源，API 优先，Playwright fallback：

```
ScraperRouter（根据配置/可用性选择）
  ├── API Engine（xhs 库 + Flask 签名服务）
  └── Playwright Engine（现有逻辑）
```

API Engine：
- 用 `xhs` 库调小红书 Web API
- 自动后台启动 Flask 签名服务
- 二维码扫码登录（终端显示链接）
- 返回完整帖子：标题 + 正文 + 图片 + 评论 + 标签

Playwright Engine（fallback）：
- 保持现有逻辑
- API 不可用时自动切换
- 手动指定 `--engine browser`

两种引擎返回统一 Post 模型，下游 AI 逻辑不变。

## 2. 对比功能

新增命令：
```bash
xhs-research compare "A" "B" --limit 15
```

流程：
1. 分别搜索 A 和 B
2. AI 交叉分析（观点对比、价格、推荐倾向）
3. 输出对比报告（表格 + 分析 + 适合谁）

## 3. CLI 命令汇总

```bash
xhs-research search "关键词" [--limit N] [--engine api|browser]
xhs-research compare "A" "B" [--limit N]
xhs-research config-path
```

## 4. 依赖变化

保留：playwright, openai, typer, rich
